# Vklass (alpha)

Unofficial Home Assistant integration for the Vklass school platform (Sweden).

Per child: care times, attendance, next lesson, lunch menu, gym days, absences,
grades and course judgements where available. Account level: unread messages,
notifications and recent news.

**Alpha:** expect parser breakage when Vklass changes its pages. Please report issues
with the diagnostics file attached (it contains no names or ids).
